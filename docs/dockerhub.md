# strm-scraper

给 115 / LitePan 生成的 `.strm` 文件补上海报、背景图和 NFO 的刮削器，跑在 Docker 里。自带网页控制台，手机和电脑都能用，不用进容器改配置。

**Emby 和 Jellyfin 同时支持**：图片比例和命名按两家规范输出，同一份文件两边都能识别，不需要为谁单独复制一套。

```
影片目录/
├── 某影片.AVI.strm          ← 原来的 strm，一个字都不动
├── 某影片.AVI.nfo           ← 生成
├── 某影片.AVI-poster.jpg    ← 生成（2:3 竖版海报）
├── 某影片.AVI-fanart.jpg    ← 生成（16:9 横版背景图）
└── 某影片.AVI-thumb.jpg     ← 生成（16:9 缩略图，可选）
```

## 快速开始

```bash
mkdir -p /vol1/1000/docker/strm-scraper && cd /vol1/1000/docker/strm-scraper
```

新建 `docker-compose.yml`：

```yaml
services:
  strm-scraper:
    image: 3548784/strm-scraper:latest
    container_name: strm-scraper
    restart: unless-stopped
    ports:
      - "6666:6666"
    volumes:
      - ./config:/config                    # 配置目录，必须
      - /vol1/1000/LitePan/strm:/media      # 媒体库，可映射多个
    environment:
      TZ: Asia/Shanghai
```

```bash
docker compose up -d
```

浏览器打开 `http://NAS地址:6666`，用 `admin` / `admin` 登录（登录后可在「设置 → 账号」里改）。

默认不会自动刮削：点「开始任务」才开始跑。想要到点自己扫，去「自动化」页建一条定时任务。

## 界面上有什么

**任务**：开始（整库增量，只补缺的）/ 全量重刮（整库覆盖）/ 暂停 · 继续 / 取消。暂停只停止派发新任务，在跑的会收尾；取消会让进行中的条目退回待处理，下次接着做。列表可按状态筛选、搜索片名或路径，勾选后可批量删除——只从列表移除，或者连已生成的图片和 NFO 一起删（`.strm` 本身永远不动）。

**文件管理**：直接浏览媒体库，面包屑 + 上一级，目录后面标着里面有几个 strm；每个文件的海报 / 背景图 / NFO 有没有、多大一眼可见。勾哪个文件夹就只跑哪个，不会顺手把别的目录拉起来；「开始刮削」只补缺，「开始重刮」才覆盖旧图。只允许操作 `scan.roots` 里的路径。

**自动化**：一条任务 = 监控范围 + 间隔 + 执行方式，可以建多条并行管不同目录。

| 能设什么 | 说明 |
|---|---|
| 监控范围 | 全部媒体库，或点进某个媒体库 / 子文件夹后「设为当前目录」，只刮这里（含子目录） |
| 间隔 | 最小 5 分钟、最长 7 天，另有每小时 / 6 小时 / 12 小时 / 每天快捷选项 |
| 执行方式 | 增量只补新文件和缺产物的；全量范围内全部重刮并覆盖 |
| 启用 / 停用 | 停用后不再自动跑，任务保留，随时再开 |

到点自动开跑，跑完把结果和下次时间写回卡片；任意时刻只跑一轮，撞车那次顺延到下一轮。任务存在 `state.db` 里，重建容器不丢。

**手动选帧**：自动挑的帧不满意，点「选帧」自己选——滚轮缩放 1×–8×、拖动平移、拖四个角调整裁切框（白框 + 九宫格 + 角把手，比例按 2:3 锁）、Alt 画新框、方向键微调，点「确定裁切」覆盖海报和背景图。手选位置记进状态库，以后重刮一直沿用。

**自动抓帧**：按片长比例采样 5 个时间点，边缘检测方差挑最清晰的一帧，不是固定截中间那张；快速跳转失败自动退回解码定位，网络源不支持 Range 也能出图；自动过滤纯黑帧和色块帧。

**支持的视频格式**：`.strm`（默认，读取里面记录的 http/https/rtsp 地址）以及 `mp4` / `mkv` / `avi` / `ts` / `m2ts` / `mov` / `wmv` / `flv` / `rmvb` / `webm` / `mpg` / `m4v` 等本地文件。判断依据是 ffmpeg：能探测到画面就能出图。文件名后缀可在 `scan.extensions` 里增减，默认只有 `.strm`。

**图片规格**（符合 Emby / Jellyfin 要求）

| 产物 | 比例 | 默认尺寸 | 文件名 |
|---|---|---|---|
| 海报 | 2:3 | 1000×1500 | `<名称>-poster.jpg` |
| 背景图 | 16:9 | 1920×1080 | `<名称>-fanart.jpg` |
| 缩略图 | 16:9 | 1000×562 | `<名称>-thumb.jpg` |

海报默认满幅裁切（`crop`）：横版视频也铺满整张 2:3，不会缩在中间、上下留背景条；竖版源纵向略微上偏，避免切到额头。想保留留白效果可在设置里换成 `blur`（模糊背景补边）或 `gradient`（渐变补边）。换完模式旧海报不会自己重画，勾上目录点「开始重刮」才覆盖。

比例写错会自动校正并在日志里告警，不会被媒体服务器拉伸裁切。

**媒体服务器联动**：同时配置多台 Emby / Jellyfin，刮完自动重建图片缓存；三种认证头依次尝试；刷新参数同时写 body 和 query（Jellyfin 12.x 只认 body）；刷新后回查，确认识别到了图。

**设置与日志**：扫描目录、并发、超时、海报模式、JPEG 质量、Emby / Jellyfin 地址与密钥、账号密码都能在网页里改，保存即生效。日志三路输出（控制台 / 滚动文件 / 网页实时），可按级别和关键字筛选、一键下载；`docker exec strm-scraper python -m scraper.main --doctor` 一次查完 ffmpeg、目录、状态库、服务器连通性。

## 配置

首次启动自动生成 `config/config.yaml`。大多数项在网页「设置」里改即可，也可以用 `WS_` 前缀的环境变量：

```yaml
WS_SCAN__CONCURRENCY=4
WS_LOG__LEVEL=DEBUG
```

定时任务请在网页「自动化」页里管理；旧版本的 `scan.interval_minutes` 会自动迁移成一条「全部媒体库」任务。
